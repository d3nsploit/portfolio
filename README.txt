BIRTHDAY WEBSITE FOR YOUR WIFE

1. Put your wife's/couple photo at:
   assets/couple.jpg

2. Keep this folder structure:
   birthday-wife/
     index.html
     assets/
       couple.jpg

3. Open index.html locally to preview.

GITHUB PAGES:
- Create a GitHub repository.
- Upload index.html and the assets folder.
- Repository Settings > Pages.
- Deploy from the main branch / root.
- GitHub will provide your public website URL.

CUSTOMIZATION:
- Replace the Malay text in index.html with your own story.
- The website is intentionally dependency-light; the only external resource is Google Fonts.
